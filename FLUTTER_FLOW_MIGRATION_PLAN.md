# 🚀 План миграции Rocky RDF Bot на Flutter Flow

> **Цель:** Перенести фронтенд-часть проекта на Flutter Flow, сохранив при этом n8n для автоматизации и Airtable в качестве базы данных
> **Статус документа:** 📋 Планирование | **Версия:** 2.0 | **Дата:** 20 ноября 2025 г.

## 📊 Анализ текущей архитектуры

### Текущий стек (v3.2)
- **Фронтенд:** HTML/CSS/JS Web Apps (Vercel Hosting)
- **Бэкенд:** Vercel Functions (API Endpoints)

## 🔧 Технические детали интеграции

### Flutter Flow + Supabase

#### 1. Настройка подключения
```dart
// В настройках Flutter Flow
Supabase URL: https://your-project.supabase.co
Supabase Anon Key: your-anon-key
```

#### 2. Аутентификация через Telegram
```dart
// Проверка Telegram initData и создание/получение пользователя
Future<User> authenticateWithTelegram(Map<String, dynamic> telegramData) async {
  final response = await supabase
    .from('users')
    .select()
    .eq('chat_id', telegramData['user']['id'])
    .single();
    
  if (response == null) {
    // Создание нового пользователя
    return await createUser(telegramData);
  }
  
  return User.fromJson(response);
}
```

#### 3. Realtime подписки
```dart
// Подписка на обновления вызывных листов
supabase
  .from('callsheets')
  .on(SupabaseEventTypes.all, (payload) {
    // Обработка изменений в реальном времени
    handleCallsheetUpdate(payload);
  })
  .subscribe();
```

### n8n + Supabase

#### 1. HTTP Request узел для Supabase
```json
{
  "method": "POST",
  "url": "https://your-project.supabase.co/rest/v1/users",
  "headers": {
    "apikey": "your-service-role-key",
    "Authorization": "Bearer your-service-role-key",
    "Content-Type": "application/json"
  },
  "body": {
    "chat_id": "{{$json.chat_id}}",
    "username": "{{$json.username}}",
    "first_name": "{{$json.first_name}}",
    "status": "Pending"
  }
}
```

#### 2. Workflow для регистрации
```
Telegram Trigger → Extract User Data → Check User in Supabase → 
Create User if Not Exists → Notify Admin → Handle Admin Response
```

## 🚨 Стратегия миграции данных

### 1. Экспорт из Airtable
```python
# Скрипт для экспорта данных
import pandas as pd
from airtable import Airtable

def export_users():
    airtable = Airtable(base_key, table_name, api_key)
    records = airtable.get_all()
    df = pd.DataFrame([record['fields'] for record in records])
    df.to_csv('users_export.csv', index=False)
```

### 2. Трансформация и импорт в Supabase
```sql
-- SQL скрипт для импорта данных
COPY users(chat_id, username, first_name, last_name, phone, payment_details, notes, role, status)
FROM 'users_export.csv'
WITH (FORMAT csv, HEADER true);
```

### 3. Проверка целостности данных
```sql
-- Проверка количества записей
SELECT COUNT(*) FROM users;

-- Проверка дубликатов chat_id
SELECT chat_id, COUNT(*) 
FROM users 
GROUP BY chat_id 
HAVING COUNT(*) > 1;
```
