## 💻 Старые версии кода

### `cloudflare-worker-v1.js`
- **Дата архивации:** 10 ноября 2025 г.
- **Причина:** Заменён на `cloudflare-worker-secure.js` и `cloudflare-worker-debug.js`
- **Описание:** Промежуточная версия Worker с валидацией Telegram initData
- **Особенности:** 
  - Полная валидация initData через HMAC-SHA256
  - Проверка Whitelist
  - Rate Limiting через KV
- **Почему заменён:** Создана более структурированная версия с разделением на production (secure) и debug режимы

### `index-placeholder.html`
- **Дата архивации:** 10 ноября 2025 г.
- **Причина:** Простая заглушка, не используется
- **Описание:** HTML-заглушка для корня проекта
- **Почему заменён:** Не нужна, все Web Apps размещаются на GitHub Pages в отдельном репозитории
